- Los archivos de ejecución se distribuyen sin modificaciones. Se omiten los archivos `AGENTS.md` y `README.md` del paquete original.

Actualizar mediante una versión oficial fijada y repetir las pruebas de ciclo de vida y convivencia. La selección de la copia activa entre plugins corresponde al cargador de Action Scheduler.
